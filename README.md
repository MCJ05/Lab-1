## Frågor
1. Vad är skillnaden mellan gid add och git commit?
Git ad används när man vill lägga till en fil på engång medans Git commit är en sparad version av ett projekt, det har unikt ID samt ett tillhörande meddelande som beskriver ändringarna. 

2. Varför använder man branches istället för att jobba direkt i main?
För att kunna säkerhetställa att man inte råkat ta bort projektet samt när man testköra programmet i branches kan det vara lättare att hitta problemet.

3. Vad händer rent praktiskt när man gör en merge?
Genom en merge sammanför man en branch med main vilket gör att ändringarna man tidigare gjort i en branch förs in i main och blir en del av den.

4. Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på tex netlify?
Den största skillnaden mellan de två är att det som sparas på GitHub blir versions sparat vilket betyder att koden lagras medans om man skulle publicera till Netlify blir koden en ofentlig webbplats.

5. Om du vill exkludera någon fil i projektet från verisionshantering, hur gör du då?
Genom att skapa en .gitignore-fil kan man exkludera en viss fil från verisionshanteringen.
